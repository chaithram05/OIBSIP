Project 2:# BMI Calculator Using Python

## About the Project
A simple Python program that calculates Body Mass Index (BMI) based on the user's weight and height.

## Features
- Accepts weight in kilograms and height in centimetres.
- Calculates BMI using the standard formula.
- Displays the BMI category.
- Handles non-numeric input using try-except.
- Rejects zero and negative values with helpful error messages.

## Technologies Used
- Python
- Conditional Statements
- Exception Handling

## BMI Formula
BMI = Weight (kg) / Height (m)²

## How to Run
1. Download the BMI calculator Python file.
2. Open the terminal in the project folder.
3. Run:

   python "BMI calculator.py"

4. Enter your weight and height when prompted.

# 🔐 Random Password Generator Using Python

## 📌 Project Overview

The Random Password Generator is a beginner-friendly Python project that generates strong and random passwords based on user-defined preferences.

The application allows users to specify the desired password length and generates a password using a combination of uppercase letters, lowercase letters, numbers, and special characters.

The project uses Python's built-in `random` and `string` modules to generate passwords automatically. It helps users understand how random selection works in Python while developing a simple command-line application.

## 🎯 Features

- Allows users to specify the desired password length.
- Generates random passwords automatically.
- Includes uppercase letters (A–Z).
- Includes lowercase letters (a–z).
- Includes numeric digits (0–9).
- Includes special characters (!, @, #, $, etc.).
- Provides a unique password for each generation.
- Validates user input to avoid invalid password lengths.

## 🛠️ Technologies Used

- **Programming Language:** Python 3
- **Modules:**
  - `random` – Selects random characters.
  - `string` – Provides predefined collections of letters, digits, and special characters.

## 💻 Python Concepts Applied

- Variables and Data Types
- User Input (`input()`)
- Type Conversion (`int()`)
- Conditional Statements (`if-else`)
- Loops
- String Manipulation
- Random Character Selection
- Built-in Python Modules
- Exception Handling (`try-except`), if implemented

## ⚙️ How It Works

1. The program asks the user to enter the desired password length.
2. It creates a collection of uppercase letters, lowercase letters, numbers, and special characters.
3. Python randomly selects characters from the available collection.
4. The selected characters are combined to generate a password.
5. The generated password is displayed on the screen.

## ▶️ How to Run the Project

**Step 1:** Clone the repository.

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**Step 2:** Navigate to the project directory.

```bash
cd Random-Password-Generator
```

**Step 3:** Run the Python file.

```bash
python password_generator.py
```

**Step 4:** Enter the required password length and generate your password.
