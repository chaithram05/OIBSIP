# BMI Calculator Using Python

## About the Project
A simple Python program that calculates Body Mass Index (BMI) based on the user's weight and height.

## Features
- Accepts weight in kilograms and height in centimetres.
- Calculates BMI using the standard formula.
- Displays the BMI category.
- Handles non-numeric input using try-except.
- Rejects zero and negative values with helpful error messages.

## Technologies Used
- Python
- Conditional Statements
- Exception Handling

## BMI Formula
BMI = Weight (kg) / Height (m)²

## How to Run
1. Download the BMI calculator Python file.
2. Open the terminal in the project folder.
3. Run:

   python "BMI calculator.py"

4. Enter your weight and height when prompted.
